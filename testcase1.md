# Test Cases - Online Jewellery System

| Test Case ID | Test Case | Input | Expected Result |
|---|---|---|---|
| TC01 | User Registration | Valid user details | Account should be created |
| TC02 | User Login | Valid email and password | User should login successfully |
| TC03 | Browse Jewellery | Open jewellery section | Jewellery products should be displayed |
| TC04 | Search Jewellery | Enter jewellery name | Matching products should be displayed |
| TC05 | View Product | Select a jewellery item | Product details should be displayed |
| TC06 | Add to Cart | Select product and click Add to Cart | Product should be added to cart |
| TC07 | Remove from Cart | Select product and click Remove | Product should be removed from cart |
| TC08 | Place Order | Valid delivery details | Order should be placed successfully |
| TC09 | Invalid Delivery Details | Missing delivery information | Error message should be displayed |
| TC10 | Order History | Open order history | Previous orders should be displayed |
| TC11 | Product Unavailable | Select unavailable product | System should show unavailable message |
| TC12 | Logout | Click Logout | User should be logged out |
